# Безопасность

## Пароли и секреты

- Не коммитьте реальные пароли БД, `EMBED_API_KEY` и другие секреты в репозиторий.
- Строка подключения `PG_DSN` храните в `~/.hermes/.env` или переменных окружения на сервере.
- Скрипт `setup_memory_db.sh` передаёт пароль приложения через переменную `MEMORY_DB_PASSWORD` (не в argv `psql`).

### Ротация пароля

Если пароль production-БД когда-либо попадал в git (в том числе в старых коммитах), **смените пароль роли PostgreSQL** и обновите `PG_DSN` на всех хостах, где развёрнута память. Переписывать историю git не требуется — достаточно нового пароля на сервере.

```bash
# пример (от суперпользователя)
psql -d postgres -c "ALTER ROLE hermes PASSWORD 'новый_секрет';"
```
